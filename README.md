## 📖 About the Project
**SENU** is a comprehensive mobile solution designed to assist students at *Instituto Tecnológico de Oaxaca*. It solves navigation and information accessibility problems within the campus through an intuitive interface and real-time data.

## 🚀 Key Features
* **📍 Interactive Geolocation:** Real-time campus navigation using **Google Maps API**.
* **🔥 Real-time Data:** Instant updates on events and announcements via **Cloud Firestore**.
* **🔐 Secure Auth:** Student verification system using **Firebase Authentication**.
* **🎨 Modern UI:** Developed with **Flutter** for a smooth, native experience on Android/iOS.
